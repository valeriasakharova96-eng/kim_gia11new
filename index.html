Изменения в КИМ ЕГЭ-2027
Изменения в КИМ ЕГЭ-2027 по информатике
Поменялась структура записи ответа на задание 27. Теперь в ответе нужно будет записать строку из двух чисел вместо двух строк из двух чисел каждая.
Изменения в КИМ ЕГЭ-2027 по истории
Общее количество заданий увеличили с 21-го до 22-х.
На позицию 15 добавили задание на работу с историческим источником по всеобщей истории.
Максимальный первичный балл увеличится с 42-х до 43-х.
Скорректировали формулировку задания 20 (по нумерации 2026 года – 19). Теперь задание проверяет понимание исторических понятий и умение их использовать.
Из задания 22 (по нумерации 2026 года – 21) исключили материал по всеобщей истории. Максимальный балл за задание уменьшили с 3-х до 2-х баллов.
В демонстрационный вариант КИМ добавили приложение с параграфами государственных учебников по истории, которые содержат учебный материал по каждому заданию ЕГЭ.
